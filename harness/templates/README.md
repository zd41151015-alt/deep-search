# Template Boundary

`scaffold-request.current.json` drives
`npm run harness -- scaffold-artifact --file FILE`. Change `kind` to produce an Intake,
execution planning, Research Task, parallel dispatch, readiness, Gap, Adaptation Decision, or
terminal report source scaffold. The command validates every generated document against the current
schema and marks semantic fields as caller-required; it never introduces facts, conclusions,
references, or external actions.

The default allocation is 65% customer/commercial behavior, 17% market structure or regulatory
material, and 18% academic mechanism, boundary, or counterevidence. These percentages are planning
guidance only: actual query counts do not have to match them, and deviation is not a publication
Gate. Actual adopted-source distribution is derived from Evidence Register records rather than an
agent's reported percentages. Hard Gates apply to qualifying, current, dimension-specific commercial
coverage. The allocation is not a money budget or execution deadline.
