# Adaptation Runtime Ownership

G0.4 owns deterministic machine-gap drafts, Adaptation Decision policy checks, immutable Plan Revision application, stale-base compare-and-swap behavior, retry/supersede lineage, late-artifact exclusion, idempotency, and crash-boundary recovery.

Semantic gap selection stays with the main agent. G0.1 publishes only fail-closed command names and does not create Gap Snapshots, approve actions, or mutate plans.
