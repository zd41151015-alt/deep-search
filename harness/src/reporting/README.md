# Reporting Ownership

G1.4 owns concept-assessment `report.json`, decision brief, full report, traceability, and consistency evaluation. G2.4 extends the same structured-source rule to discovery comparison and portfolio outputs.

`audit-traceability` consumes one explicit closed assessment or discovery bundle and returns a structured, non-zero-on-failure audit. `build-report` consumes one explicit v7 assessment, v12/v13 discovery, or v17 terminal main-agent report envelope, then publishes report, decision brief, report Markdown, and consistency sidecars in fixed order. v17 handles complete or early-exit terminal delivery without inventing unexecuted comparison/portfolio Artifacts. It localizes fixed text and enums from `research_language`, keeps readable sources in the primary brief, moves internal refs to the audit appendix, and renders ordered, testable product hypotheses from caller-supplied judgment. Exact replay is byte-stable; same-path, receipt, source/hash, scan, or materialized drift fails closed. Reopen may complete a validated partial publish, but it cannot invent or revise judgment content.
