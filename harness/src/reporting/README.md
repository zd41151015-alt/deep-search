# Reporting Ownership

G1.4 owns concept-assessment `report.json`, decision brief, full report, traceability, and consistency evaluation. G2.4 extends the same structured-source rule to discovery comparison and portfolio outputs.

Report generation consumes validated artifact references and may not invent facts or conclusions. G0.1 has no reporting implementation; `build-report` and `audit-traceability` remain fail-closed.
