# Reporting Ownership

G1.4 owns concept-assessment `report.json`, decision brief, full report, traceability, and consistency evaluation. G2.4 extends the same structured-source rule to discovery comparison and portfolio outputs.

`audit-traceability` consumes one explicit closed assessment or discovery bundle and returns a structured, non-zero-on-failure audit. `build-report` consumes one explicit v7 assessment or v12/v13 discovery main-agent report envelope, then publishes report, decision brief, report Markdown, and consistency sidecars in fixed order. v13 derives Consistency v3 and scans the structured source plus both rendered Markdown views for forbidden validation-success, probability, and global-score language before publication. It materializes `report.json`, `decision-brief.md`, and `report.md` from immutable sidecars. Exact replay is byte-stable; same-path, receipt, source/hash, scan, or materialized drift fails closed. Reopen may complete a validated partial publish, but it cannot invent or revise judgment content.
