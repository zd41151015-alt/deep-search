# Comparison Ownership

G2.4 owns hard gates, the four-panel comparison, evidence conclusion ceilings, pairwise dominance, sensitivity, partial-order relations, and portfolio outputs under a versioned policy. Unknown inputs remain unknown, and evidence strength does not add opportunity attractiveness.

`calculate-comparison` and `calculate-sensitivity` accept one closed validated document bundle and return deterministic summaries of caller-supplied Artifacts and their canonical hashes. They do not create panel bands, Judgment, rankings, recommendations, Evidence, or published Artifacts. Invalid or incomplete bundles fail closed.
