# Deterministic Eval Boundary

G0.2 provides schema integrity and explicit Document Bundle typed-reference checks. G0.4 adds deterministic Research Plan semantics, machine Gap Snapshot construction, and closed Adaptation Decision policy evaluation. Later Harness-level evaluators add freshness, research-quality constraints, decision readiness, traceability, and three-output consistency. Each evaluator is introduced with representative passing, revision-required, insufficient-evidence, and failing fixtures in its owning slice.

Repository checks remain in `tests/skeleton.test.ts`; schema/reference checks live in `tests/schema-validation.test.ts`; G0.4 runtime checks live in `tests/g0.4-runtime.test.ts`. None is evidence that research-quality, comparison, or report evaluators exist.
